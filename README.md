# TaskManager (GitPractice)

Учебный проект для практической работы №4–5 «Настройка работы системы контроля версий (типов импортируемых файлов в репозиторий). Настройка работы системы контроля версий (путей в репозиторий)».

## Описание проекта

**TaskManager** — это настольное приложение на платформе .NET 8.0 (C# Windows Forms), предназначенное для учёта и управления задачами.

### Основные возможности:
- Добавление, редактирование и удаление задач;
- Установка приоритетов (Низкий, Средний, Высокий, Критический);
- Отметка о выполнении задач;
- Поиск и фильтрация задач по названию и статусу;
- Валидация входных данных;
- Просмотр статистики и экспорт задач в JSON (ветка `AddFunction`);
- Демонстрация полного цикла работы с Git и GitHub (ветвление, слияние, разрешение конфликтов).

## Требования для сборки и запуска
- Windows 10/11
- .NET 8.0 SDK / Visual Studio 2026 Community / Enterprise
- Git 2.40+

## Запуск проекта
```bash
dotnet build GitPractice.sln
dotnet run --project GitPractice.csproj
```
